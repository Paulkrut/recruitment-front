# ⚡ Оптимизация глобального слайдера времени

## Проблема

Глобальный слайдер времени (в `QuestionTimeSettings`) тоже **тормозил** при движении по тем же причинам:

```
Движение слайдера
  ↓ onChange вызывает onChange prop (60 раз/сек)
  ↓ Родитель обновляет templateData.questionTime
  ↓ Родитель обновляет ВСЕ вопросы (умная логика)
  ↓ React перерендеривает всю страницу
  ↓ 🐌 ТОРМОЗА
```

**Дополнительно:** Дизайн слайдера был упрощенным и отличался от индивидуального слайдера в вопросах.

---

## Решение

### 1. Оптимизация производительности

Добавили **локальный state + debounce**, как в индивидуальном слайдере:

```typescript
// 🔥 Локальный state
const [localValue, setLocalValue] = useState(value);
const timeoutRef = useRef<NodeJS.Timeout | null>(null);

// Синхронизация с props
useEffect(() => {
  setLocalValue(value);
}, [value]);

// Debounced update (500ms)
const handleTimeChange = (newValue: number) => {
  setLocalValue(newValue);
  
  if (timeoutRef.current) {
    clearTimeout(timeoutRef.current);
  }
  
  timeoutRef.current = setTimeout(() => {
    onChange(newValue);
  }, 500);
};
```

### 2. Улучшение дизайна

Сделали дизайн **идентичным индивидуальному слайдеру**:

**До:**
```
Кнопки: [60] [90] [120] [150] [180] ...

Слайдер: |————————————————|
         1 мин            5 мин
```

**После:**
```
Кнопки: [60] [90] [120] [150] [180] ...

┌─────────────────────────────────────┐
│ 🕐 Глобальное время                  │
│                                      │
│ [180] сек  |——————●———————|  3:00   │
│            1мин  3мин  5мин  10мин   │
│                                      │
│ Время, отведенное на ответ...       │
└─────────────────────────────────────┘
```

**Новые элементы:**
- ✅ **Числовое поле** для точного ввода
- ✅ **Метки времени** на слайдере (1 мин, 3 мин, 5 мин, 10 мин)
- ✅ **Отображение MM:SS** справа от слайдера
- ✅ **Иконка часов** для визуального акцента
- ✅ **Рамка и фон** для выделения блока
- ✅ **Подсказка** о возможности индивидуальной настройки

## Технические детали

### Кнопки быстрого выбора

```typescript
<Button
  onClick={() => {
    // Мгновенно обновляем БЕЗ debounce (явное действие)
    setLocalValue(time);
    onChange(time);
    
    // Отменяем pending debounce от слайдера
    if (timeoutRef.current) {
      clearTimeout(timeoutRef.current);
    }
  }}
>
  {time} сек
</Button>
```

**Почему без debounce?**  
Клик на кнопку — это **явное действие пользователя**, результат должен быть мгновенным.

### Слайдер

```typescript
<Slider
  value={localValue}  // 🔥 Локальный state
  onChange={(_, newValue) => handleTimeChange(newValue as number)}
  marks={[
    { value: 60, label: '1 мин' },
    { value: 180, label: '3 мин' },
    { value: 300, label: '5 мин' },
    { value: 600, label: '10 мин' },
  ]}
  valueLabelDisplay="auto"
  valueLabelFormat={(value) => `${Math.floor(value / 60)}:${(value % 60).toString().padStart(2, '0')}`}
/>
```

### Числовое поле

```typescript
<TextField
  type="number"
  value={localValue}  // 🔥 Локальный state
  onChange={(e) => {
    const newValue = parseInt(e.target.value);
    if (!isNaN(newValue) && newValue >= minTime && newValue <= maxTime) {
      handleTimeChange(newValue);  // 🔥 Debounced
    }
  }}
  inputProps={{ min: minTime, max: maxTime, step: 30 }}
/>
```

### Отображение времени

```typescript
<Typography variant="h6">
  {Math.floor(localValue / 60)}:{(localValue % 60).toString().padStart(2, '0')}
</Typography>
```

## Результаты

### Производительность

#### До оптимизации:
```
Движение слайдера
  ↓ 60 вызовов onChange/сек
  ↓ 60 обновлений state родителя
  ↓ 60 обновлений всех вопросов (умная логика)
  ↓ Сотни ре-рендеров
  ↓ 🐌 ТОРМОЗА
```

#### После оптимизации:
```
Движение слайдера
  ↓ Обновляется только localValue
  ↓ Ре-рендер только QuestionTimeSettings (быстро)
  ↓ 0 обновлений родителя
  ↓ ⚡ ПЛАВНО!

... пользователь отпускает ...
  ↓ 1 вызов onChange (через 500ms)
  ↓ Умное обновление вопросов
  ↓ React.memo предотвращает лишние ре-рендеры
```

### UX

| Аспект | До | После |
|--------|----|----|
| **Дизайн** | Упрощенный | Идентичен индивидуальному |
| **Числовое поле** | ❌ Нет | ✅ Есть (точный ввод) |
| **Отображение времени** | Опционально внизу | ✅ Всегда справа (MM:SS) |
| **Метки слайдера** | Только по краям | ✅ 1, 3, 5, 10 мин |
| **Производительность** | 🐌 Тормозит | ⚡ Плавно |
| **Подсказка** | Общая | ✅ С упоминанием индивидуальной настройки |

## Консистентность дизайна

Теперь **оба слайдера** (глобальный и индивидуальный) имеют **идентичный UI**:

### Общие элементы:
- Числовое поле слева (100px)
- Слайдер в центре с метками
- Отображение MM:SS справа (70px)
- Одинаковые цвета и стили
- Одинаковая логика debounce (500ms)

### Различия (по функциональности):
| Элемент | Глобальный | Индивидуальный |
|---------|------------|----------------|
| **Рамка** | Серая | Серая/Синяя (если кастомное) |
| **Иконка** | 🕐 Часы | ⏱️ Секундомер |
| **Заголовок** | "Глобальное время" | "Время на ответ" |
| **Бейдж** | ❌ Нет | ✅ "Индивидуальное" (если отличается) |
| **Кнопка сброса** | ❌ Нет | ✅ Есть (если отличается) |
| **Кнопки быстрого выбора** | ✅ Есть | ❌ Нет (компактность) |
