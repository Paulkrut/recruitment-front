# 📝 HTML редактор для вопросов — Краткая сводка

## Что добавлено

✅ **HTML редактор** с форматированием для текста вопросов  
✅ **Автоопределение** формата (HTML vs plain text)  
✅ **100% обратная совместимость** с существующими вопросами

---

## Возможности редактора

- **Жирный**, *курсив*, <u>подчеркнутый</u>
- Маркированные и нумерованные списки
- Ссылки
- Переносы строк

---

## Как работает

### В админке (редактирование)
```
CustomTextField → RichTextEditor
```

Toolbar: `[B] [I] [U] [•] [1.] [🔗] [🧹]`

### В интервью (отображение)
```
Автоопределение:
  - Есть HTML теги? → рендер как HTML
  - Нет тегов? → рендер как plain text (как раньше)
```

### Обратная совместимость
```
Старые вопросы с \n:
  - При просмотре: работают как раньше
  - При редактировании: \n → <br> автоматически
```
